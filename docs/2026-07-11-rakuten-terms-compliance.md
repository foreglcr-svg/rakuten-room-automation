# 楽天ROOM利用規約の変更点と自動化範囲のコンプライアンス適合性調査

- 実施日: 2026-07-11 ／ 実施: NOREN 法務コンプラ部（タスク 292e7fad）
- 注記: 本書は社内レビュー。規約・API仕様は改定されるため、運用継続前に楽天の**最新の一次情報**（ROOM利用規約・楽天ウェブサービス規約・アフィリエイト規約）を必ず確認すること。

## 1. 現在の自動化範囲と規約の関係

| 工程 | 自動/手動 | 規約適合性 |
|---|---|---|
| 商品リサーチ（楽天市場API） | 自動 | ✅ 公式API利用。applicationId/accessKey/Origin・Referer検証に対応済み |
| 紹介文生成（Gemini） | 自動 | ✅ 生成物の作成は自由。NG表現は辞書＋プロンプトで抑制 |
| カタログ更新・通知 | 自動 | ✅ 自リポジトリ内の生成物 |
| **ROOMへの投稿** | **手動** | ✅ **最重要**。ボット自動投稿はROOM規約違反→アカウント停止・報酬没収。最後の一手を人間にすることで回避 |

**結論の骨子**: 現設計は「投稿だけ人間」により規約の核心リスクを回避しており、**現状の自動化範囲は適合的**。

## 2. 継続確認すべき変更点（チェックリスト）

1. [ ] 楽天ウェブサービス（市場API）の**利用規約・レート/用途制限**の最新版（新APIキー形式・accessKey・Origin/Referer検証は対応済み）
2. [ ] **アフィリエイト規約**: 成果対象・禁止事項（自己アフィリ、誤認誘導リンク等）
3. [ ] **ROOM利用規約**: 自動化/ボット/多重アカウントの禁止条項（投稿手動を維持する限り核心は回避）
4. [ ] **景表法ステマ規制（2023〜）**: アフィリ収益がある投稿は「広告/PR」の明示が必要。紹介文テンプレに明示を入れる余地
5. [ ] **薬機法・景表法**: 効能断定/誇大表現の禁止（辞書＋プロンプトで対応済み・辞書の網羅性を定期見直し）

## 3. リスクと対応

- **最大リスク**: 将来「投稿も自動化したい」と踏み込むこと。これはROOM規約違反に直結するため、**やらない**方針を明文で維持（README に既に明記あり）。
- **中リスク**: ステマ表示。アフィリを使うなら「#PR」等の明示を紹介文に組み込む改善を推奨。
- **低リスク**: NG語辞書の抜け。季節商品追加時に新たな効能表現が混じらないか定期点検。

## 4. 法務コンプラ部の結論

**現在の自動化範囲は規約適合的**で、設計に「投稿は人間」という正しい防波堤がある。継続運用にあたっては、①ステマ表示（#PR）の追加検討、②各規約の最新版の定期確認、の2点を推奨。自動投稿への拡張は規約上不可のため実装しない。詳細な解釈が要る場合は専門家確認を。
